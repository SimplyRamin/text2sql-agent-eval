    How correctness is judged
    
Correct means the result set matches the ground truth, not the SQL text.
      Column names and column order are ignored. Numbers match within 0.01 (or 0.01% for large values).
      Row order only matters when the question asks for an order. NULL matches NULL.
      So a query that looks different from the ground truth can still be marked correct.
